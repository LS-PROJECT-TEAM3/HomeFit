# spec: 팔로우한 공고를 알림 없이 내 일정에 넣기

## 1. 해결하려는 문제
지금은 팔로우한 공고에 **변화가 생겨 알림(사건)이 오고 그 대응안을 승인해야** 내 일정에 신청 준비가 생긴다. 변화가 없는 공고는 팔로우해도 일정에 넣을 길이 없어, 사용자가 마감을 따로 챙겨야 한다. [spec 001 FR-020] [PRD FR-16]

## 2. 주요 사용자
일반 사용자: 맞춤 공고를 보고 신청하기로 한 사람 (P1)

## 3. 핵심 기능과 요구사항
### FR-001 공고 상세에서 내 일정에 추가 (P1) [IA NT_080100_PG] [PRD FR-16]
팔로우 중인 공고의 상세에 "내 일정에 추가" 버튼을 보인다. 누르면(사용자의 승인) 그 공고의 신청 준비 일정이 내 일정에 생긴다. 제목 = 공고 이름, 마감일 = 신청 마감, 체크리스트 = 기본 신청 준비 체크리스트(자격 확인, 서류 준비, 마감 전 신청). 이미 넣었으면 버튼 대신 "내 일정에 있음"과 일정 링크를 보인다.
### FR-002 한 공고는 한 번만 (P1) [PRD FR-16 "두 번 눌러도 일정 1개"]
같은 사람이 같은 공고를 두 번 넣어도 일정은 1개다.
### FR-003 팔로우한 공고만 (P1) [CLAUDE.md 사람 승인]
팔로우하지 않았거나 관심 없음으로 한 공고는 서버가 거절한다. 다른 사람 일정에는 쓸 수 없다.
### FR-004 일정 상세의 출처 (P1) [IA SC_060100_PG]
알림에서 온 일정은 "출처 알림 보기", 공고에서 온 일정은 "출처 공고 보기"로 이어진다. 체크·마감 표시는 기존과 같다.

### 하지 않을 것
- 팔로우하면 자동으로 일정 넣기(누를 때만), 가짜 사건 만들기, 일정 지우기, 정책(006) 일정 넣기
- 알림에서 온 일정과 공고에서 온 일정 합치기(같은 공고가 나중에 알림으로 오면 일정이 2개가 될 수 있다 → Q1)

## 3-1. 경계·예외
- E1 팔로우 안 함·관심 없음 → 거절 "팔로우한 공고만 일정에 넣을 수 있습니다"
- E2 두 번 누름 → 같은 일정
- E3 신청 마감 없는 공고 → 마감일 없음, 체크리스트 "신청 기간을 공고문에서 확인하기"
- E4 로그인 안 함 → 로그인 화면
- E5 없는 공고 ID → 거절

## 4. 성공 기준
- SC-001: 팔로우한 공고 상세에서 버튼을 누르면 내 일정 목록에 그 공고가 마감일과 함께 보인다.
- SC-002: 두 번 눌러도 일정은 1개다.
- SC-003: 팔로우하지 않은 공고로 DB 함수를 부르면 거절된다.
- SC-004: 공고에서 온 일정 상세에 "출처 공고 보기" 링크가 있고 체크가 저장된다.
- SC-005: 375px에서 가로 넘침이 없다.

## 5. 제외 범위
일정 지우기, 정책 일정, 같은 공고의 알림 일정과 합치기.
