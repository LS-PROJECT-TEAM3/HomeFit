## 1. 해결하려는 문제
비밀번호를 잊으면 다시 들어올 방법이 없다. 로그인 화면에 재설정 길이 없어서 새 계정을 만들어야 하고, 그러면 내 집·조건·일정이 모두 사라진 것처럼 보인다. [PRD FR-32] [IA MB_010300_PG] [코드 app/(auth)/login/page.tsx]

## 2. 주요 사용자
- 모든 회원: 비밀번호를 잊었을 때 메일로 새 비밀번호를 정한다 (P1)

## 3. 핵심 기능과 요구사항
### FR-001 재설정 메일 요청 (P1) [PRD FR-32] [IA MB_010300_PG]
로그인 화면에 "비밀번호를 잊으셨나요?" 링크를 둔다. 재설정 화면에서 이메일을 넣으면 Supabase Auth가 재설정 링크를 메일로 보낸다. 가입한 이메일인지와 상관없이 같은 안내("메일을 보냈습니다…")를 보인다(가입 여부를 알려 주지 않기 위해).
### FR-002 메일 링크로 새 비밀번호 정하기 (P1) [PRD FR-32] [IA MB_010301_PG]
메일 링크를 누르면 새 비밀번호 화면이 열린다. 새 비밀번호와 확인 칸을 받아, 8자 이상이고 두 칸이 같을 때만 바꾼다(가입 규칙과 같음, spec 001). 바꾸면 홈으로 간다.
### FR-003 링크 오류 안내 (P1)
링크가 만료됐거나 이미 썼거나 다른 브라우저에서 열어 확인할 수 없으면, 재설정 화면으로 돌아와 "링크가 만료됐거나 이미 쓰였습니다. 메일을 다시 요청해 주세요."를 보인다.

### 하지 않을 것
- 직접 메일 서버(SMTP)·유료 메일 서비스 연결(외부 서비스는 먼저 묻는다, Q1)
- 문자·소셜 로그인으로 재설정, 비밀번호 바꾸기 화면(로그인한 상태에서 바꾸기)은 이번에 하지 않음
- 메일 문구(템플릿) 바꾸기(Supabase 기본 문구)

## 3-1. 경계·예외
- E1 이메일 칸이 비었거나 이메일 모양이 아니면 메일을 보내지 않고 고칠 방법을 알린다
- E2 가입하지 않은 이메일도 같은 안내(FR-001)
- E3 메일 요청이 너무 잦아 Supabase가 막으면 "잠시 뒤 다시 요청해 주세요"
- E4 새 비밀번호가 8자 미만이면 거절, 두 칸이 다르면 거절, 앞뒤 공백도 글자로 센다(가입과 같음)
- E5 링크 없이 새 비밀번호 화면을 열면(로그인 안 됨) 로그인 화면으로 간다
- E6 링크 코드가 틀리거나 만료되면 FR-003
- E7 이미 로그인한 사람이 재설정 화면(메일 요청)을 열면 홈으로 간다(로그인·가입 화면과 같음)

## 4. 성공 기준
- **SC-001** 로그인 화면에서 두 번 눌러 재설정 메일을 요청할 수 있다
- **SC-002** 메일 링크로 새 비밀번호를 정하고 그 비밀번호로 로그인된다
- **SC-003** 입력 오류·만료 링크마다 무엇이 안 됐고 무엇을 하면 되는지 한국어로 보인다
- **SC-004** 재설정 화면이 가입 여부를 드러내지 않는다

## 5. 제외 범위
3절 "하지 않을 것"과 같다.
