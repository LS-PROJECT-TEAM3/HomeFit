## 0. 흐름 1에서 그대로 가져올 규칙
- 색: 흰색, 회백색 #F6F4F2, 딥그린 #4E5B4E(주 버튼, 현재 위치), 브라운 #55463D(글씨), 어두운 갈색 #4A3F37, 연한 초록 #EEF1EE. 의미 색은 빨강 #A12B2B(위험, 거절), 황토 #8A5A12(주의, 대기, 마감 임박)만
- 글씨: 본문 Pretendard 16px, 보조 15px, 라벨 14px 이상. 제목과 큰 숫자는 Noto Serif KR. 숫자는 자리 폭 맞춤
- 모양: 모서리 4px 이하, 테두리로 감싼 박스 대신 면 색으로 구분, 아이콘 최소, 문장 안 구분 "|", 단어 사이 "/"
- 입력 칸: 흐름 1 첫 설정과 같은 칸, 같은 접힘 묶음, "입력함 4/5" 표시
- 상태는 색만으로 알리지 않고 글자를 함께. PC 1440px와 휴대폰 375px 두 벌

## 1. 메뉴 구조 (확정 2026-11-20)
```
[HomeFit]  홈  맞춤 공고  알림  내 일정  더보기 ▾            현경 ▾
                                         ├ 집 비교              ├ 로그인한 계정
                                         ├ 집 점검              ├ 설정
                                         ├ 에너지 분석          ├ 관리자 (관리자만)
                                         └ AI 도우미            └ 로그아웃
```
- 드롭다운은 "더보기"와 오른쪽 "이름" 두 개뿐. 나머지 메뉴는 누르면 바로 이동
- 더보기 안 화면에 있을 때는 상단 바의 "더보기"에 현재 위치 표시
- 휴대폰: "메뉴"를 열면 위에 주 메뉴 5개, 그 아래 더보기 4개, 맨 아래 계정 묶음(설정, 관리자, 로그아웃)
- 드롭다운은 키보드로 열고(Enter), 고르고(방향키), 닫힘(Esc)이 되어야 함
- **그려 줄 것**: 더보기 펼친 모습, 이름 펼친 모습(일반 / 관리자), 휴대폰 메뉴 펼친 모습

## 2. 화면별로 담을 것

### 2-1. 집 비교 (`/compare`) — 계약 전, 보고 있는 집들을 한 달 실제 지출로 비교
- 화면 소개 한 줄: "보고 있는 집들을 월세 / 관리비 / 에너지비 / 교통비를 더한 실질 주거비로 비교합니다"
- 탭 3개
  1. **관심 주택**: 등록한 집 목록, "+ 관심 주택 등록". 등록 칸: 이름(상세 주소는 받지 않음, "내가 알아볼 이름만"), 시도 *, 주택 유형 *, 전용면적(선택), 월세, 관리비, 교통비(편도 요금 × 하루 횟수 × 출근 일수). 집마다 상세 화면(고치기)
  2. **실질 비용 비교**: 내 집과 관심 주택을 나란히. 칸마다 값의 종류를 표시(입력 / 계산 / 추정값). 빈 칸은 "미입력"이고 합계에서 빠짐. "내 집 대비" 차이
  3. **추천 결과**: "실질 주거비가 낮은 순서". 네 칸이 모두 찬 집만 순위에 넣음. 점수 없음
- 디자인에서 풀 것: 가장 싼 집과 그 차이가 한눈에. 값마다 입력 / 계산 / 추정값 구분이 보이게(색만 말고 글자로). 에너지비 계산 근거 문구는 접어 두되 찾을 수 있게
- 빈 화면: "아직 등록한 관심 주택이 없습니다. 보고 있는 집을 넣으면 내 집과 한 달 실질 주거비를 비교합니다." / 순위 못 만들 때: "네 칸이 모두 찬 관심 주택이 없어 순위를 만들지 않았습니다. 아래 집의 빈 칸을 채워 주세요."
- 지킬 것: 개인화 추천 점수 금지(하지 않을 것). 민간 매물 가져오기 없음(사용자가 직접 입력)

### 2-2. 집 점검 (`/qc`) — 계약 전에 집 상태를 살피고, 사는 동안 결로 / 습기를 관리
- 탭 4개
  1. **결로 위험 시뮬레이터**: 실내 온도, 실내 습도, 바깥 기온, 창 종류(이중유리 / 모름은 홑유리로 계산). 숫자를 바꾸면 바로 결과. 저장 안 함. 결과에 "계산한 추정값이라 실제와 다를 수 있습니다"
  2. **입주 전 품질 점검**: 관심 주택을 골라 채광 / 소음 / 곰팡이 / 수압 같은 항목 체크와 메모. 관심 주택이 없으면 등록으로 안내
  3. **주거환경 / 하자 기록**: 실내 온습도 기록(추이), 하자 기록(생긴 날, 종류, "무엇이 어떻게" 500자, 사진 1장 jpg / png / webp 4MB, 본인만 봄)
  4. **건축물 기본 정보**: 시도, 시군구, 읍면동, 번지 본번 / 부번 → 용도, 구조, 사용승인일, 층수, 세대수, 연면적, 내진설계. "넣은 주소는 저장하지 않습니다. 출처: 국토교통부 건축HUB. 실제 안전 인증 / 판정이 아닙니다"
- 디자인에서 풀 것: 시뮬레이터 결과(위험 단계)가 크게, 글자와 색 함께. 탭 4개가 휴대폰에서 넘치지 않게
- 빈 화면: "아직 하자 기록이 없습니다", "내 집을 등록하면 실내 온습도 기록이 여기에 쌓입니다", 건축물 못 찾음 "그 번지의 건축물대장을 찾지 못했습니다. 읍면동과 번지를 확인해 주세요."
- 지킬 것: 안전 판정, 하자 원인 / 책임 판정, 누수 예측 하지 않음

### 2-3. 에너지 분석 (`/energy`) — 지금 사는 집의 전기 / 가스 요금을 미리 짐작
- 탭 3개
  1. **예상 에너지 사용량**: 한 달 예상 전기 사용량(kWh). 누진 1 / 2 / 3구간 막대 위에 "내 위치". 사용량을 안 넣었으면 그 지역 한전 가구 평균으로 추정
  2. **월별 예상 비용**: 12개월 예상 전기요금, 이번 달 / 가장 많은 달 표시, 부가세 별도와 "부가세 포함 어림", "사용량을 줄이면" 비교
  3. **냉난방비 시뮬레이션**: 도시가스 공급 지역과 한 달 사용량(MJ)을 넣으면 계산. 저장 안 함
- 디자인에서 풀 것: 추정값인지 내가 넣은 값인지가 숫자 옆에 보이게. 누진 구간 막대가 휴대폰에서도 읽히게. "기본요금 + 전력량요금만, 부가 요금 제외" 안내 자리
- 빈 화면: 내 집이 없을 때 "내 집을 넣으면 그 지역 기준으로 예상 사용량과 요금을 보여 드립니다" + 내 집 입력 링크. 통계 없음 / 조회 실패는 다른 문구
- 지킬 것: 전기요금 변경 사건은 만들지 않음

### 2-4. AI 도우미 (`/knowledge`) — 내가 처리한 알림 기록 찾기
- 탭 3개
  1. **기록 찾기**: "찾을 낱말이나 질문" 입력 → AI 답 + 찾은 기록 목록(기록마다 알림 링크). 승인 / 거절로 끝난 알림에서만 찾음
  2. **처리 기록 (최근 20건)**: 끝난 알림 목록
  3. **공공데이터 출처**: 자료, 쓰는 곳, 어디서 / 얼마나 자주, 이용 조건 표(기상청은 출처 표시가 이용 조건)
- 디자인에서 풀 것: 답과 출처의 관계가 한눈에. AI 답을 못 만들어도 찾은 기록은 보여 줌("AI 답을 만들지 못했습니다. 아래 찾은 기록을 직접 열어 보세요.")
- 빈 화면: "아직 처리한 알림이 없습니다. 알림을 승인하거나 거절하면 여기에 쌓입니다." / 결과 없음: "승인 / 거절로 끝난 알림 가운데 맞는 것이 없습니다."

### 2-5. HomeFit 챗봇 (모든 화면 오른쪽 아래) — 이번에 새로 확인한 것
- 지금 앱의 모든 화면 오른쪽 아래에 "챗봇" 버튼이 있고, 누르면 "HomeFit 챗봇" 창이 열린다 (spec 004 FR-007)
- 답하는 자료: 내 알림 / 일정, 내 집 / 관심 주택 / 하자 기록, 공공데이터(마이홈 공고, 청년 주거 정책, 기상청 예보). 답마다 출처, 머리글 "내 기록 / 공공데이터로 답함"
- 첫 인사 예시: "관심 주택 실질 주거비 비교해 줘", 입력 칸 예시 "결로 알림에 뭘 했지?"
- 디자인에서 풀 것: 닫힌 버튼, 열린 창(질문, 답, 출처, 찾는 중 "기록과 공공데이터를 찾는 중…", 오류 "답을 만들지 못했습니다"), 휴대폰에서 하단 고정 버튼이 있는 화면(공고 상세, 알림 상세)과 겹치지 않게
- AI 도우미와 겹치는 점은 아래 Q1

### 2-6. 설정 (`/my`를 대신함) — 알림이 맞게 오도록 넣는 정보
- 이름 드롭다운 → 설정. 탭 4개. 입력 칸은 흐름 1 첫 설정과 같은 부품
  1. **내 집**: 시도 / 시군구 *, 주택 유형 *, 전용면적 *, 창 종류 *(모름 가능), 계약 묶음(월세 / 전세, 월세, 관리비, 만료일), 실내 온습도 입력(측정값이 7일 넘으면 "오래된 측정값"). "누수 / 건물 하자는 이 앱으로 알 수 없습니다. 결로 / 습도 위험만 알려 드립니다."
  2. **공고 / 정책 조건**: 시도 / 시군구 *, 공급 유형, 월 임대료 상한(선택), 나이(선택), 대상(선택, "자격은 공고문에서 확인해 주세요")
  3. **관심 지역**: 시도, 시군구 여러 곳, 주택 유형, 기준 면적(±20% 거래만 비교), 계약 형태. "최근 3개월 실거래 중간값이 지난번보다 10% 이상 바뀌면 알려 드립니다"
  4. **슬랙 알림**: 켜기 / 끄기, 팀 슬랙 이메일. "슬랙 알림을 켜는 것이 알림을 받겠다는 승인입니다. 대응 계획은 지금처럼 하나씩 승인합니다."
- 디자인에서 풀 것: 저장 후 "저장했습니다" 안내, 슬랙 알림 켬 / 끔 상태가 글자로도 보이게

### 2-7. 이름 드롭다운 (내 계정 역할)
- 로그인한 계정 표시 → 설정 → 관리자(관리자 역할에만) → 로그아웃
- "내 계정" 화면은 만들지 않음(지금 계정 화면에는 계정 표시와 로그아웃뿐)

### 2-8. 관리자 (`/admin`, 관리자만) — 평가 시연과 운영 점검
- 탭 8개: 개요, 회원, 수집 현황 / 오류(연속 실패, "지금 한 번 실행"), 사건 현황, 흐름 화면(수집 → 사건 → 승인 대기 상자 그림), 시뮬레이터(가짜 자료로 전체 흐름 시연), 채점 결과(맞힘 / 놓침 / 잘못 울림), 위키 챗봇(기획 문서에 묻는 챗봇)
- 우선순위 낮음: **개요와 흐름 화면 두 장만** 그려 주면 나머지는 Claude가 같은 규칙으로 맞춘다
- 지킬 것: 관리자도 사용자 대신 승인할 수 없다. 흐름 화면 상태는 색 + 선 모양 + 글자 라벨로 구분(아래 Q2)

## 3. 화면마다 필요한 상태
- 빈 화면, 불러오는 중, 조회 실패(“데이터 없음”과 다른 문구), 저장 완료
- 휴대폰 375px에서 가로 스크롤 없음. 탭이 많으면(집 점검 4개, 관리자 8개) 가로로 밀어 보는지, 줄바꿈하는지 정해서 그리기
