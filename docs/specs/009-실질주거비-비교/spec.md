## 1. 해결하려는 문제
집을 고를 때 월세만 보고 관리비·에너지비·교통비를 나중에 알아 실제 한 달 비용이 예상보다 커진다(P01 "계약 전에 관리비를 알 수 없었다", A01 가상). 내 집과 보고 있는 집을 같은 기준(한 달 실질 주거비)으로 비교할 곳이 없다. [문제정의 알파] [PRD FR-28]

## 2. 주요 사용자
- 준비형: 이사할 집 후보를 비교 (P1)
- 자취형: 공고를 보며 지금 집보다 한 달에 얼마나 다른지 (P1)

## 3. 핵심 기능과 요구사항
### FR-001 관심 주택 등록·수정·지우기 (P1) [IA CP_040100_PG, CP_040300_PG] [ERD interest_homes]
이름, 시군구, 주택 유형, 전용면적(선택), 보증금(선택), 월세, 관리비(선택), 에너지비(직접 입력 또는 전기 사용량 kWh, 선택), 교통(편도 요금, 하루 횟수 기본 2, 한 달 출근 일수 기본 22, 선택)을 넣는다. 상세 주소는 받지 않는다. 잘못된 값은 칸 아래 이유와 할 일. 작성자·시각 저장.
### FR-002 내 집 비용 칸 (P1) [ERD homes v1.9]
내 정보 → 내 집에 같은 에너지비·교통 칸을 더한다(모두 선택).
### FR-003 실질 주거비 계산 (P1) [PRD FR-28] [GLOSSARY 실질 주거비]
실질 주거비 = 월세 + 관리비 + 에너지비 + 교통비. 에너지비: 직접 입력 > 전기 사용량으로 계산 > 미입력. 교통비 = 편도 요금 × 하루 횟수 × 한 달 출근 일수. 빈 칸은 0으로 넣지 않고 "미입력"으로 표시하고 합계 옆에 "미입력 N개 빠짐"을 알린다.
### FR-004 전기요금 계산 (P1) [한전 주택용 저압 요금표]
전기 사용량(kWh)과 이번 달로 기본요금 + 전력량요금(누진 3단계, 하계 7~8월 300·450kWh, 그 밖 200·400kWh, 1,000kWh 넘는 부분 736.2원)을 계산한다. 화면에 "계산값(한전 요금표, 부가세·기금·기후환경·연료비조정 제외)"을 밝힌다.
### FR-005 비교표 (P1) [IA CP_040200_PG]
내 집과 관심 주택을 한 표에: 월세·관리비·에너지비·교통비·합계, 내 집 대비 차이(+/−원). 합계가 낮은 순. 칸마다 값의 종류(입력값 / 계산값 / 미입력)를 글자로 보인다.
### FR-006 공고 상세의 내 집 대비 (P2) [IA NT_080100_PG] [문제정의 알파]
공고 상세에 "내 집 월세보다 한 달 +N원(공고 최저 월세 기준)"을 보인다. 관리비·에너지비·교통비는 "공고문 확인". 내 집 계약이 없거나 공고 월세가 없으면 줄을 보이지 않는다.

### 하지 않을 것
- 면적 기준 에너지비 추정, 에너지 분석 화면(다음 spec 012, 근거 통계 확인 뒤), 부가세·기금 포함 요금, 도시가스 요금 계산
- 보증금·월세 전환율, 추천 점수, 매물 크롤링(PRD 9절)

## 3-1. 경계·예외
- E1 사용량 200kWh(평소) → 910 + 200×120 = 24,910원. 201kWh → 1,600 + 200×120 + 1×214.6 = 25,814원(원 미만 버림)
- E2 7월 300kWh → 1단계(910 + 36,000)
- E3 1,100kWh(8월) → 1,000kWh 넘는 100kWh는 736.2원
- E4 직접 입력과 kWh가 둘 다 있으면 직접 입력
- E5 빈 칸 → 미입력, 합계에서 빠짐, 0으로 보이지 않음
- E6 교통 칸 중 편도 요금이 없으면 교통비 미입력. 하루 횟수·출근 일수가 비면 2·22
- E7 내 집이 없거나 계약이 없음 → 비교표에 내 집 줄 대신 "내 집을 넣으면 차이가 보입니다"
- E8 관심 주택 입력 오류(월세 음수, 이름 비움·40자 넘음, kWh 0~3000 밖, 편도 요금 0~20,000 밖) → 칸 아래 오류
- E9 다른 사람 관심 주택 → 보이지도 고치지도 못함(RLS)

## 4. 성공 기준
- SC-001: 관심 주택 2개를 넣으면 비교표에 내 집과 함께 합계 낮은 순으로 보이고 새로고침·재로그인 뒤에도 남는다.
- SC-002: E1~E6이 함수 시험으로 통과한다.
- SC-003: 공고 상세에 내 집 대비 월세 차이가 보인다(계약이 있을 때).
- SC-004: 새 화면이 375px에서 가로로 넘치지 않는다.

## 5. 제외 범위
