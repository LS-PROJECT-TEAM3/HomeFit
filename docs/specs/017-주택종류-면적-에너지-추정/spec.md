# spec: 주택 종류·면적에 맞춘 에너지 사용량 추정

- 기능 ID: 017
- 상태: 초안 v0.1 (사용자 지시 2026-11-19 "관리비나 에너지 관련은 입력이 없을 경우 아파트 오피스텔 빌라 같은 건물 종류랑 평수에 따라 평균으로", 추천안 "추천대로 진행", "에너지 평균 만들어". plan까지 함께 씀. **spec 승인 전**)
- 작성일 / 최종 갱신: 2026-11-19 / 2026-11-19
- 근거 문서: docs/PRD.md v1.15(FR-28), docs/specs/011-에너지-추정(FR-001·FR-002, E2), docs/specs/009-실질주거비-비교, ERD homes·interest_homes(housing_type, exclusive_area_m2), 에너지경제연구원 「가구에너지패널조사」 14차(2023년 기준) 결과표
- 다음 문서: plan.md, qa.md

## 1. 해결하려는 문제
지금 에너지비 추정은 한전 시군구 가구 평균 하나만 쓴다. 같은 동네라면 원룸 오피스텔과 30평대 아파트가 같은 전기 사용량으로 추정돼 실질 주거비 비교가 틀어진다. 한전 값을 불러오지 못하면 추정 자체를 하지 못한다. [spec 011 FR-001 "면적은 반영하지 않는다"] [사용자 요청 2026-11-19]

## 2. 주요 사용자
- 준비형: 원룸·투룸·아파트처럼 크기와 종류가 다른 관심 주택을 비교할 때 에너지비가 집에 맞게 어림되길 바란다 (P1)

## 3. 핵심 기능과 요구사항
### FR-001 주택 종류·면적 보정 (P1) [사용자 요청] [가구에너지패널조사 14차]
에너지비를 넣지 않았고 사용량(kWh)도 모르는 집은, 가구에너지패널조사의 가구당 연간 일반전기 사용량으로 보정한다.
- 보정 비율 = (그 집 면적 구간의 전국 값 ÷ 전국 평균) × (그 집 주택 종류의 전국 값 ÷ 전국 평균). 면적을 모르면 면적 비율은 1
- 주택 종류: 아파트 → 아파트, 연립·다세대 → 다세대/연립/기타, 오피스텔 → 다세대/연립/기타(Q1), 단독·다가구 → 단독
- 면적 구간: 33㎡ 미만, 33~66㎡, 66~99㎡, 99~132㎡, 132㎡ 이상(결과표 구간 그대로)
### FR-002 지역 값과 함께 쓰기 (P1) [spec 011 FR-001]
한전 시군구 가구 평균이 있으면 "시군구 평균 × 보정 비율"을 한 달 추정 사용량으로 쓴다. 한전 값을 불러오지 못했거나 그 시군구 값이 없으면 "패널조사 전국 평균(연간 ÷ 12) × 보정 비율"을 쓴다. 쓰는 순서(입력 > kWh 계산 > 추정 > 미입력, spec 011 FR-002)는 그대로다.
### FR-003 근거 표시 (P1)
추정값 아래 근거 글에 한전 통계와 함께 패널조사 이름·기준 연도를 적고, 주택 종류·면적으로 보정했다는 것을 적는다. 한전 값을 못 불러온 곳은 "전국 평균으로 추정"이라고 적는다.

### 하지 않을 것
- 관리비 평균(아파트는 K-apt 파일을 받은 뒤 다음 spec, 오피스텔·빌라는 공식 통계가 없어 미입력 그대로)
- 시도별 패널 값(표본이 작아 상대표준오차가 큼), 주택 종류 × 면적을 함께 나눈 표(결과표에 없음)
- 도시가스 사용량 추정(냉난방비 계산은 입력만, spec 016)

## 3-1. 경계·예외
- E1 직접 입력이나 kWh가 있으면 추정하지 않는다(spec 011 E1 그대로)
- E2 면적이 없으면 주택 종류 비율만 쓴다
- E3 면적 구간 경계: 33㎡는 33~66㎡ 구간(결과표 "33-66㎡미만"), 132㎡는 132㎡ 이상
- E4 한전 값을 불러오지 못하거나 0 이하면 패널 전국 평균으로 추정(spec 011 E2의 "미입력"을 바꿈)
- E5 추정값은 소수 첫째 자리로 반올림한 kWh, 요금은 기존 요금표 계산 그대로

## 4. 성공 기준
- **SC-001** 같은 시군구에서 면적이 작은 집의 추정 에너지비가 큰 집보다 낮게 나온다
- **SC-002** 한전 값을 못 불러와도 관심 주택의 에너지비가 "추정값"으로 채워진다
- **SC-003** 근거 글에서 어떤 통계로 어떻게 보정했는지 알 수 있다

## 5. 제외 범위
3절 "하지 않을 것"과 같다.
