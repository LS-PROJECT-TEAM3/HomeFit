# 커넥터 활용 기록

출처: 안내서 4절 "AI와 커넥터", 평가항목 P3-19.
기준일: 2026-11-18 (main `65ed611`). 6.2절(DB 변경 0022~0025)은 2026-11-23 main `e8050f7`의 파일과 PR 설명으로 더했다.

**커넥터**는 개발할 때 Claude가 외부 서비스(GitHub, Supabase, Notion, Google Drive 같은)에 연결해 일을 하는 길이다. 안내서 4절은 "서로 다른 서비스로 **실제 일**을 한 것"을 적으라고 하고, 설치만 한 것은 세지 않는다. 앱이 부르는 API(마이홈, 기상청, 슬랙 봇 등)는 별개라 [data-sources.md](data-sources.md)에 있다.

이 문서는 **확인된 사실만** 적는다. 쓰지 않은 것을 쓴 것처럼 채우지 않았고, 확인하지 못한 곳은 `확인 필요`로 둔다. 토큰과 키는 적지 않는다.

대상: Supabase 프로젝트 HomeFit의 `public` 스키마. 비교한 문서는 `Yelim` 브랜치의 `docs/ERD.md` v1.9와 `supabase/migrations/`(0001~0017, 0020).

| 확인 | 결과 |

### 6.1 대조한 뒤 바뀐 것 (2026-11-18 저녁, 예림님 확인)
위 표는 오후에 대조한 시점의 모습이다. 그 뒤 DB가 바뀌었다.
- `audit_logs`: 조각 B에서 마이그레이션 0019로 만들었다(PR #11). ERD에만 있던 표 5개 중 하나가 생긴 것이다.
- `chat_logs`: 대조 때는 DB에만 있고 저장소 파일과 DB의 마이그레이션 기록에는 없었다(칸 6개, RLS 켜짐, 정책 2개, 행 2개). **현경님이 조각 A를 만들며 SQL 편집기로 먼저 적용한 것**이고(현경님 답, 2026-11-18), 파일 `0018_wiki_chat_logs.sql`이 PR #15로 main에 들어왔다(2026-11-19). 파일은 `if not exists`로 써서 이미 표가 있는 DB에 다시 돌려도 멈추지 않는다. **DB의 마이그레이션 기록에는 여전히 0018이 없다.** 현경님은 2026-11-19에 "그대로 둔다"로 정했다(spec 012 plan 5절: 팀은 `db push`를 쓰지 않고, 쓰기로 하면 그때 기록표 전체를 파일과 맞춘다). 팀 전체가 같이 정한 것인지는 확인 필요.
- 2026-11-18 기준 DB의 마이그레이션 기록은 **19개**(0001~0017, 0019, 0020)였다. 그 뒤 0021이 더해졌다(아래). 맨 앞 4개는 번호 없는 이름(`first_feature_tables` 등)으로 적용됐고, 0018은 기록에 없다(SQL 편집기로 넣어서. 0019·0020이 먼저 기록됨). 저장소 파일은 이제 0001~0021이 모두 있다.
- **0021**(`0021_move_in_checks_and_defects.sql`, spec 019): `interest_homes`에 칸 2개, 새 표 `defect_records`, 비공개 저장소 `defect-photos`를 만든다. 예림님이 PR #19가 합쳐지기 전에 Supabase 커넥터(`apply_migration`)로 공용 DB에 먼저 적용했다고 PR #19 설명에 적혀 있다. 예림님은 2026-11-19 11:19(한국 시각)에 Supabase 관리 도구로 적용했고 DB의 적용 기록에도 남아 있다고 답했다(PR #26 리뷰). 예림님이 `list_migrations`로 센 지금 기록은 **20개**(0001~0017, 0019, 0020, 0021)이고, 0018은 여전히 기록에 없다(표는 DB에 있음, PR #26 리뷰 2026-11-19). 선우가 직접 세지는 않았다. 파일은 `if not exists`·`drop … if exists`로 써서 다시 돌려도 멈추지 않는다.
- 이 변화는 선우가 다시 읽어 확인한 것이 아니라 예림님이 DB에서 확인해 알려 준 것이다. 조각 A·B와 PR #19가 합쳐졌으니(PR #11, #15, #19) 다시 대조해야 한다. 2026-11-19 현재 다시 대조하지 않았다. 위 표의 "표 20개, 정책 35개"는 0021 전의 값이다.
