# CUJ 3: 시세 사건 → 재계약 판단 메모 승인

## 개요
| 항목 | 내용 |
|---|---|
| 유형 | OEC 기반 |
| 선정 근거 | P01이 가장 큰 손해로 꼽음(1명). [ADR 0002](../../adr/0002-인터뷰로-사건-종류-다시-고르기.md)에서 근거가 약한 것을 알고 넣음 |
| 핵심 사용자 | 자취형(내 집), 준비형(관심 지역) |
| OEC/핵심 지표 | 계약 만료 전에 시세 사건을 받은 비율 |

## 목표 (JTBD)
> "재계약이나 이사를 결정해야 할 때, 나는 주변 집들이 실제로 얼마에 계약됐는지 알고 싶다. 그래서 비싸다고 착각해 손해 보는 결정을 하지 않을 수 있다."

## 핵심 터치포인트 (5개)
| # | 과업 | 화면 ID | 감정 (점수) | 생각 | 인사이트 | MOT | 지표 | 목표치 |
|---|---|---|---|---|---|---|---|---|
| 1 | 내 집 계약 정보(금액, 계약 형태, 만료일) 입력 | MY_030200_TB | 0 (가설) | | 계약 금액이 없으면 비교할 수 없음 | | 계약 정보 입력률 | |
| 2 | 시세 사건 카드를 봄 | HM_000000_PG | 0 (가설) | "올랐나 내렸나?" | | | 처음 본 시각 | |
| 3 | 사건 상세에서 주변 거래 비교표(중간값, 거래 수, 기간)를 봄 | IC_020100_PG | -1 → +1 (가설) | "내가 비싼 건가?" | P01 "주변보다 나았던거니까" — 비교 근거가 판단을 바꿈 | ✔ | 상세 → 승인 비율 | |
| 4 | 재계약 판단 메모 승인 | IC_020101_MD | +1 (가설) | | | | 승인 비율 | |
| 5 | 계약 만료 2달 전 일정 확인 | SC_060100_PG | +1 (가설) | | | | 만료 전 확인 비율 | |

**갈림길: 관심 지역(준비형)**. 1번 대신 관심 지역(MY_030300_TB)을 등록한다. 4번은 "관심 주택 다시 보기" 승인으로 바뀌고, 관심 주택 목록(2차)에 반영된다.

## Moment of Truth
- **3. 비교표**: 거래 수가 적은데 중간값만 보여 주면 잘못 판단하게 만든다. 거래 수, 기간, 비교 조건(면적 ±20%, 같은 계약 형태)을 함께 보여 주고, 거래가 적으면 사건을 만들지 않는다.

## 제외한 터치포인트와 이유
- 집주인에게 연락하기: 서비스 밖의 행동이다. 메모에 "이야기할 점"만 담는다.

## 페인포인트 → 개선안
| 페인포인트 | 근거 | 개선안 | 기대 지표 변화 |
|---|---|---|---|
| 결정한 뒤에야 시세를 찾아봄 | P01 "이미 본가로 돌아온 후에" | 만료 전 월 1회 비교 | 만료 전 사건 비율 |
| 보증금·월세 섞인 비교가 어려움 | 가설 | 같은 계약 형태끼리만 비교(문제정의) | |

## 검증
- 근거가 1명이라 사용성 테스트에서 "재계약 때 이 정보가 판단을 바꾸는가"를 확인한다.
