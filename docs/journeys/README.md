## 페르소나
인터뷰에서 겹치는 특징을 묶은 것이다. 실제 인물 한 명을 그대로 옮기지 않는다.

### 준비형: 취업하면 다른 지역으로 독립할 사회초년생
- 근거: P01, P02, P04 (모두 부모님 집), A01(가상)
- 이용 맥락: 지원한 회사 주변을 부동산 앱으로 수시로 본다(P01 "오늘도 알아봤어"). 공고·정책은 SNS·검색으로 "지나가다" 본다(P04).
- 기대: 조건에 맞는 공고·정책과 집의 실제 비용을 미리 알기
- 걱정·불만: 관리비·안전을 확인할 길이 없어 "나중에 알아보려고 미뤄놨어"(P01). 정책은 "무슨 말인지 잘 모르겠어서"(P04).
- 쓰는 CUJ: 1, 3(관심 지역)

### 자취형: 혼자 월세로 사는 사회초년생
- 근거: P03, P01(자취 시절)
- 이용 맥락: 한 집에 1~2년 산다. 습도계로 습도를 재고 제습기를 돌린다(P03).
- 기대: 곰팡이·누수 같은 피해를 생기기 전에 막기, 재계약 때 손해 보지 않기
- 걱정·불만: 누수·곰팡이로 "침실은 아예 사용도 못하고"(P03). 시세를 몰라 재계약하지 않은 일을 "가장 손해"로 꼽음(P01).
- 쓰는 CUJ: 2, 3(내 집)
