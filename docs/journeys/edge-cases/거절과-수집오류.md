# 예외 경로: 거절, 수집 오류, 권한

세 사건 종류(공고·정책, 습도·결로, 시세)에 모두 적용한다. 각 기능의 spec은 이 문서를 출처로 쓴다.

## E1: 대응안 거절 (IC_020102_MD)
**발생 조건:** 사용자가 사건 상세에서 "거절"을 누른다.
**사용자가 보는 것:** 거절 사유 입력 칸(필수). 예시 사유: "자격이 안 됨", "이미 처리함", "필요 없음".
**시스템 반응:** 사유·거절한 사람·시각을 기록한다. 내 일정과 다른 값은 바꾸지 않는다(P3-04). 사건 상태를 "거절"로 바꾼다.
**복구 경로:** 사건 상세의 처리 이력에 남는다. 다시 승인할 수 있는지는 spec에서 정한다(확인 필요).
**검증 방법:** 거절 뒤 내 일정 개수가 그대로인지, 사유 없이 거절이 막히는지 확인.

## E2: 수집 오류
**발생 조건:** 바깥 API 호출 실패, 시간 초과, 응답 형식 다름, 호출 한도 초과.
**사용자가 보는 것:** 해당 사건 종류 목록 위에 "(출처)에서 자료를 불러오지 못했습니다" 문구. "새 사건 없음"과 다른 문구.
**시스템 반응:** 실행 기록에 실패와 오류 메시지를 남긴다(키는 가림). "변화 없음"으로 기록하지 않는다.
**관리자가 보는 것:** 수집 현황(AD_070200_TB)에 실패 표시, 연속 실패 수.
**복구 경로:** 다음 정기 수집 또는 "지금 한 번 실행".

## E3: 입력이 비어 있어 사건이 생길 수 없음
| 사건 종류 | 비어 있는 것 | 사용자가 보는 것 |
|---|---|---|
| 공고·정책 | 공고·정책 조건 | 홈 맨 위 "조건을 입력해 주세요" |
| 습도·결로 | 내 집 또는 최근 측정값 | 홈 "실내 온습도를 입력해 주세요" |
| 시세(내 집) | 계약 금액·형태 | 내 집 탭 "계약 정보를 넣으면 주변 시세와 비교해 드립니다" |
| 시세(관심 지역) | 관심 지역 | 관심 지역 탭 안내 |

## E4: 권한 없는 접근
**발생 조건:** 일반 사용자가 `/admin` 주소나 관리자 API를 직접 부른다. 다른 사람의 사건 ID로 접근한다.
**사용자가 보는 것:** "볼 수 없는 페이지입니다" 안내와 홈 링크. 자료는 한 줄도 보이지 않는다.
**검증 방법:** 화면, 서버, DB(행 단위 권한) 세 곳에서 각각 막히는지 확인(P3-14).

## E5: 관리자가 대신 승인하려 함
**발생 조건:** 관리자가 사건 현황에서 사용자 사건을 승인하려 한다.
**사용자가 보는 것:** 관리자 화면에는 승인 버튼이 없다. 관리자 수정은 사유를 받고 기록하지만 승인 단계를 건너뛰지 못한다(P3-13).
