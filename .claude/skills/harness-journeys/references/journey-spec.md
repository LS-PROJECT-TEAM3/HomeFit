## 2. 예시: 가입 → 첫 가치 경험 (Critical, 신규, 1회성)
- **성공 지표**: 5분 안에 "아하 모먼트" 도달 비율
- **목표**: "이 제품이 내 문제를 해결하는지 빨리 써보고 싶다."
- **1단계 랜딩**: "무료로 시작" 클릭 → 가입 폼. 기준: CTA가 첫 화면에 보임, 방해 요소 없음, 가치 제안이 명확. 마찰: 입력 항목 과다 → 이메일+비밀번호만 / 소셜 로그인 없음 → 추가.
- **2단계 계정 생성**: 계정 생성, 인증 메일 발송(막지 않음), 온보딩으로 이동. 기준: 3초 이내, 이메일 인증 벽 없음(나중에 인증). 마찰: 이미 가입된 이메일 → 로그인 링크 제공 / 약한 비밀번호 → 제출 후가 아니라 입력 중에 조건 표시.
- **3단계 온보딩(빠른 성공)**: 1~2개 질문, 진행 표시. 기준: 질문 최대 3개, 건너뛰기 가능, 60초 이내.
- **4단계 첫 가치**: 핵심 행동 완료 → 성공 축하, 전달된 가치 표시, 다음 단계 제안.
- **에러**: E1 이미 가입된 이메일 → "계정이 있으신가요? 로그인 또는 비밀번호 재설정" / E2 소셜 로그인 실패 → 이메일 가입 폼으로 대체.
- **지표**: 가입→첫 가치 5분 미만, 단계별 이탈, 소셜/이메일 가입 비율, 온보딩 건너뛰기 비율.

## 3. 예시: 결제 (Critical-매출)
- **목표**: "놀랄 일 없이 빠르고 안전하게 결제하고 싶다."
- **1 장바구니 확인**: 숨은 비용 없음, 수량 수정 쉬움.
- **2 결제 시작**: 비회원 결제 가능, 간편결제 노출, 로그인 시 자동 입력, 진행 표시(1/3).
- **3 결제 정보**: 카드 검증은 입력 중에, 여러 결제 수단, 보안 표시.
- **4 완료**: 5초 이내 확인, 주문번호 명확, 다음 단계 안내.
- **에러**: E1 결제 거절 → 결제 단계에 머물며 다른 항목 유지, 다른 결제 수단 제안 / E2 결제 중 세션 만료 → 장바구니 유지, 빠른 재로그인 후 같은 단계로 복귀.

## 4. 단계별 UX 체크리스트
- **명확성**: 지금 어디인지(경로, 진행 표시) / 다음에 할 일(CTA) / 방금 일어난 일(피드백)을 아는가
- **속도**: 페이지 2초, 동작 3초 이내, 긴 작업은 진행 표시
- **관용**: 실수를 되돌리기 쉬운가, 에러가 원인을 설명하는가, 복구 경로가 분명한가
- **접근성**: 키보드 탐색, 스크린리더 안내, 포커스 관리, 색 대비
- **모바일**: 터치 영역 44px 이상, 가로 스크롤 없음, 폼 입력 시 의도치 않은 확대 없음, 느린 네트워크에서 동작

## 5. 공통 여정 패턴
- **점진적 공개**: 기본 옵션만 → "고급"에서 추가 옵션 → 전문가 모드
- **안내형 설정**: 환영+단일 선택 → 핵심 선호 → 선택적 연동(건너뛰기 가능) → 안내와 함께 첫 행동 → 성공 후 안내 제거
- **복구형**: 재방문 사용자 인식 → 이전 상태 복원 → 무슨 일이 있었는지 알림 → 명확한 다음 행동 → 원래 목표 완료

## 6. 우선순위와 테스트 주기
| 우선순위 | 기준 | 테스트 주기 |
|---|---|---|
| Critical | 매출, 핵심 가치 (= CUJ) | 배포할 때마다 |
| High | 매일 하는 행동 | 매일 |
| Medium | 주 단위 기능 | 매주 |
| Low | 예외 경로 | 변경 시 |

## 7. 작성 체크리스트
- [ ] 사용자 목표가 명확하다
- [ ] 모든 단계가 기록돼 있다 (화면 ID 연결)
- [ ] 단계별 성공 기준이 있다
- [ ] 에러 시나리오와 복구 경로가 있다
- [ ] 지표가 정해져 있다
- [ ] 테스트(E2E 또는 수동 절차)가 연결돼 있다
