# 위키에 묻기

## 순서
1. `node scripts/wiki-search.mjs 검색어`로 근거 줄을 찾는다. 위키 결과가 먼저, 원본 결과가 다음에 나온다. 못 찾으면 질문 낱말을 IA·GLOSSARY 용어로 바꿔 한 번 더 찾는다.
2. `wiki/index.md`와 찾은 위키 쪽을 읽는다.
3. 중요한 답(숫자, 날짜, 결정, 기준값)은 위키 요약만 믿지 않고 원본 줄을 다시 연다.
4. 답은 짧게. 문장마다 `(근거: 원본 경로 · 절)`.
5. 위키에도 원본에도 없으면 "위키에 없습니다, 확인 필요"라고 답한다.
6. 쪽에 `## 충돌`이 있으면 고르지 않고 둘 다 보여 준다.
7. 위키 요약과 원본이 다르면 원본을 따르고, 그 쪽이 낡았다고 알린다(고치지는 않는다).
8. 답이 다시 쓸모 있어 보이면 "위키에 남길까요?"라고 묻고 멈춘다.

## 답 모양
```text
답: (두세 문장)
근거: (원본 경로 · 절) 한 줄씩
충돌: 있으면 둘 다, 없으면 없음
확인 필요: 있으면 무엇을 누구에게
```

## 하지 않을 것
- 묻지 않고 위키나 원본 고치기
- 검색에 안 나온 사실을 기억으로 채우기
- 들은 말·가정을 확인된 사실처럼 말하기
