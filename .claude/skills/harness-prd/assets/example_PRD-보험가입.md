## 1. 요약
첫 차를 산 운전자가 개인정보 없이 보험료부터 확인하고, 10분 안에 온라인으로 가입을 끝낼 수 있게 한다. 지금은 견적을 받기 전에 개인정보와 인증을 요구해 비교 단계에서 이탈이 많다(가설).

## 2. 배경과 문제
- 문제 1 — 가격을 늦게 보여준다: 기존 방식(비교 플랫폼·설계사)은 견적 전에 개인정보를 요구해, 사용자가 비교 자체를 포기한다. (CUJ-01 "보험료 계산" 단계 As-Is, 근거: 가설)
- 문제 2 — 인증 단계가 가장 불안하다: 로그인·본인인증에서 감정 점수가 -2로 가장 낮다. 인증 후 입력값이 사라질까 걱정하고, 인증 실패 시 이탈한다. (CUJ-01 "로그인·본인인증", 근거: 가설)
- 왜 지금: 상담 없이 직접 가입하려는 수요 증가 (가설 → 8번 A1)

## 3. 목표와 성공 지표
- 비즈니스 목표: 온라인 가입 비중 확대로 상담 비용 절감
- 사용자 목표: 내 보험료를 빨리 알고, 납득되면 같은 흐름에서 바로 가입

| KPI | 현재값 | 목표값 | 측정 방법 | 기간 |
|---|---|---|---|---|
| 상품 상세 → 가입 완료 전환율 (OEC) | 4% (가설) | 8% | 이벤트 로그 퍼널 | 출시 후 90일 |
| 계산 완료율 | 측정 전 | 60% | 계산 팝업 진입 대비 결과 표시 | 출시 후 30일 |
| 인증 단계 이탈률 | 측정 전 | 20% 이하 | 인증 시작 대비 미완료 | 출시 후 30일 |

## 5. 가치 제안
### 첫 차 운전자
- **누가**: 첫 차를 산 운전자
- **왜**: 손해 보지 않는 보험에 빨리 가입하고 싶은데, 보험료를 알기까지 절차가 길다
- **이전**: 회사마다 개인정보를 넣고 인증해야 견적이 나온다
- **어떻게**: 차량 정보만으로 예상 보험료를 먼저 보여주고, 가입할 때만 로그인을 요구하며 그동안 입력한 내용을 유지한다
- **이후**: 몇 분 안에 내 보험료를 알고, 다시 입력하는 일 없이 가입까지 끝낸다
- **대안**: 비교 플랫폼, 설계사 상담 → 우리는 가격을 먼저 보여주고 가입까지 한 흐름으로 이어진다

> 개인정보 없이 내 보험료부터 확인하고, 마음에 들면 그대로 가입하는 자동차보험.

## 6. 핵심 사용자 여정 (CUJ)
### CUJ-01: 보험료 확인 후 가입
- 사용자 그룹 / 목표(JTBD): 첫 차 운전자 / "첫 차를 샀을 때, 개인정보를 넣기 전에 내 보험료부터 알고 싶다. 그래서 손해 보지 않는 선택을 빨리 끝내고 싶다."
- 유형: High-Dollar
- 사용자 스토리: "첫 차 운전자인 나는 손해 보지 않는 선택을 위해 가입 전에 내 보험료를 알고 싶다."
- 시나리오:
  1. 자동차보험 상세 (`PD_010100_PG`) — 보장 내용 확인
  2. **[MOT]** 보험료 계산 (`PD_010101_PU`) — 차량 정보만 입력해 예상 보험료 확인. 가격을 아는 순간 가입 의사가 정해진다
  3. **[MOT]** 로그인 (`MB_030000_PU`) → 신규면 회원가입 (`MB_030100_PG`) + 본인인증 (`MB_030101_LK`) — 감정 최저점(-2). 입력값 유지 여부가 이탈을 가른다
  4. 가입 정보 입력 (`PD_010102_PG`) — 계약자 정보, 약관 동의
  5. 가입 완료 (`PD_010103_PG`) → 가입 내역 (`MY_020100_TB`)에서 확인
- 감정 흐름: 상품 확인 0 → 계산 +1 → 인증 -2 → 입력 -1 → 완료 +2 (가설)
- 성공 기준: 상품 상세 진입부터 가입 완료까지 10분 이내
- 에러·복구: 본인인증 실패 → 실패 이유와 재시도 버튼 표시 → 계산 결과·입력값을 유지한 채 재시도

## 8. 결정·제약·가정
- 결정: 보험료 계산을 로그인 앞에 둔다. 대신 계산 결과는 확정 보험료가 아닌 "예상"으로 표기한다.
- 종속성: 본인인증은 외부 서비스 연동 (`MB_030101_LK`).
- 개인정보: 계산 단계 차량 정보는 저장하지 않고, 가입 시 동의 후 저장.
- 가정과 미결 질문
  - A1. 이탈 주원인은 견적 전 개인정보 요구다 (여정 근거: 가설) → 경쟁 서비스 3곳 가입 흐름 비교, 지인 5명 테스트로 확인
  - A2. 인증 단계 불안은 입력값 유실 걱정 때문이다 (가설) → 테스트에서 인증 직전 생각 말하기로 확인
  - Q1. 예상 보험료와 실제 보험료 차이 허용 범위는? → 상품팀 확인 필요
