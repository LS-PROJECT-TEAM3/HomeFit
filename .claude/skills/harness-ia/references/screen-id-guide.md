# 화면 ID 가이드

화면이 많아지면 이름만으로는 구분이 어렵다. 모든 화면에 고유 ID를 붙여 작업자 간 소통 기준으로 쓴다. 규칙은 프로젝트마다 정하기 나름이지만, 아래 기본 규칙을 쓰고 사용자가 원하면 바꾼다.

## 기본 형식

```
[메뉴 약자 2자]_[1Depth 2자리][2Depth 2자리][3Depth 2자리]_[형태 코드]
예) MY_010200_PU  →  마이페이지 > 1번째 1Depth > 2번째 2Depth, 팝업
```

1. **메뉴 약자**: 1~2 Depth 대메뉴의 영문명을 대문자 2자로 줄인다. (Main → HM, My page → MY, Product → PD, Customer service → CS, Login/Member → MB, Admin → AD)
2. **Depth 구분 코드**: 각 Depth의 순번을 두 자리 숫자로. 해당 Depth가 없으면 00.
3. **형태 코드**: IA의 형태 열에서 가져온다.

| 형태 | 코드 |
|---|---|
| 페이지 | PG |
| 팝업 | PU |
| 탭 | TB |
| 링크(외부) | LK |
| 모달/바텀시트 | MD |

## 반드시 지킬 것
- **ID는 중복되지 않는다.** 중복되면 수많은 화면 중 검색할 때 혼란이 생긴다.
- **변경·삭제된 화면의 ID는 재사용하지 않는다.** 폐기한 ID를 다시 쓰면 Depth 코드를 매길 때 중복이 생긴다. 삭제된 화면은 상태를 `삭제`로 두고 행을 남겨두거나 별도 시트로 옮긴다. 새 화면은 다음 빈 번호를 쓴다.
- 이미 공유된 ID는 이름이 바뀌어도 유지한다.

## 엑셀에서 만들기
열이 `메뉴약자(B) | 1D번호(C) | 2D번호(D) | 3D번호(E) | 형태코드(F)` 이면:
```
=CONCATENATE(B2,"_",TEXT(C2,"00"),TEXT(D2,"00"),TEXT(E2,"00"),"_",F2)
```
중복 검사: `=IF(COUNTIF($A:$A,A2)>1,"중복","")`
`scripts/build_ia_workbook.py` 가 이 두 수식을 자동으로 넣는다.
