# 디자인 기본선

취향(분위기, 색, 글꼴)은 프로젝트마다 정한다(하네스가 있으면 `harness-start` 디자인 인터뷰, 없으면 화면이 있는 첫 plan에서). 아래 기본선은 모든 프로젝트에서 지킨다. QA 단계에서 `web-design-guidelines`와 `ui-ux-pro-max` 체크리스트로 확인한다.

1. 색·간격·글꼴은 CSS 변수(디자인 토큰) 한곳에 모은다.
2. 한국어 화면은 한글 글꼴을 먼저 지정한다(예: Pretendard).
3. 글자와 배경의 명암비는 4.5:1 이상(WCAG AA).
4. 키보드만으로 조작할 수 있고, 지금 선택된 곳이 눈에 보인다.
5. 상태(예: 기한 지남)는 색만으로 구분하지 않고 글자도 함께 표시한다.
6. 휴대폰 화면 폭에서 가로 스크롤이 생기지 않는다.
7. 빈 화면, 불러오는 중, 오류 상태를 만든다.
