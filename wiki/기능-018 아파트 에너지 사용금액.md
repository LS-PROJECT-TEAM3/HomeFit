# 기능-018 아파트 에너지 사용금액

> 면적이 있는 아파트는 국토교통부 「공동주택 에너지 사용 정보」의 시군구 평균 사용금액(원/㎡, 전기·난방·급탕·가스) × 전용면적으로 한 달 에너지비를 추정한다.

## 내용
- 상태: spec·plan 초안 v0.1(사용자 지시 2026-11-19 "신청했어, 붙여", 승인 전), qa "사람 QA 끝, 1건 확인 못 함"(C 1/2, 부분 1, H 0/1 확인 못 함 1, 2026-11-20). (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · 머리말) (근거: docs/specs/018-아파트-에너지-사용금액/qa.md · 머리말)
- 문제: 아파트는 난방·급탕·가스가 크고 계절마다 크게 바뀌는데(강남구 2025년 1월 난방 1,681원/㎡, 9월 84원/㎡), 전기 kWh 추정만으로는 작게 나온다. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · 1. 해결하려는 문제)
- FR-001 아파트·면적 있음·입력 없음 → 시군구 아파트 평균 사용금액(전기+난방+급탕+가스, 수도 제외) × 전용면적. FR-002 작년 같은 달, 없으면 그 전 해 같은 달. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · FR-001, FR-002)
- FR-003 쓰는 순서: 직접 입력 > kWh 계산 > 아파트 사용금액 추정 > 전기 사용량 추정(spec 017) > 미입력. 아파트가 아니거나 면적·값이 없거나 API 실패면 spec 017. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · FR-003)
- FR-004 근거 글: API 이름·기준 달·포함 항목, 관리비 고지서에 전기·난방이 들어 있으면 에너지비를 0으로 넣으라는 안내(두 번 세지 않기). (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · FR-004)
- 경계: 모든 칸 0이면 값 없음, 응답 모양이 다르면 오류로 던지고 spec 017로 추정(팀 규칙 "읽기 실패는 오류로"), 아파트가 아니면 부르지 않음. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · 3-1. 경계·예외)
- 하지 않을 것: 관리비 평균(이 API에 없음), 오피스텔·빌라, 에너지 분석 그래프를 금액으로, 단지별 값. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · 하지 않을 것)
- 사람 QA H-1801 확인 못 함(2026-11-20, 운영 화면·관리자 가상 계정): 강남구 아파트 59㎡ 에너지비 107,321원(㎡당 약 1,819원). 그럴듯한지 판단할 기준이 없음(실제 고지서 필요). "두 번 세지 말라" 안내는 이해되지만 표 아래 문단 끝에만 있고, 관리비와 에너지비가 함께 더해진 줄에는 경고가 없다. 추천 1위 근거 글 표시는 qa 015 #1([[기능-015 추천 결과]]). (근거: docs/specs/018-아파트-에너지-사용금액/qa.md · H-1801)

## 확인 필요
- 금액 단위(원/㎡)는 명세에 없어 실제 값이 K-apt "단위면적당 사용금액"과 맞는 것으로 판단했다(가정). (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · Q1)
- 관리비와 두 번 세는 문제는 안내로만 두고 계산은 그대로(Q3). spec·plan 승인 전. H-1801은 실제 아파트 고지서가 있는 사람이 다시 볼지 팀이 정한다. (근거: docs/specs/018-아파트-에너지-사용금액/spec.md · Q3, 머리말)
