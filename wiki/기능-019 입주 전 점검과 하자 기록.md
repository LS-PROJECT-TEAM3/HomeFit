# 기능-019 입주 전 점검과 하자 기록

> 집 점검 탭의 뼈대를 마무리한 기능. 관심 주택마다 입주 전 점검 체크·메모를 저장하고, 내 집 하자를 날짜·종류·메모·사진 1장과 기록한다. 점검 기본 항목 12개·내 항목·항목별 메모는 spec 024가 더했다.

## 내용
- 상태: spec·plan 초안 v0.1(사용자 지시 2026-11-19 "뼈대만 있는거 마무리 해줘", DB 변경 "추천대로 진행", 승인 전), 마이그레이션 0021, qa "사람 QA 끝"(C 4/5, 부분 1, H 2/2, 2026-11-20). (근거: docs/specs/019-입주전점검-하자기록/spec.md · 머리말) (근거: docs/specs/019-입주전점검-하자기록/qa.md · 머리말)
- FR-001 입주 전 품질 점검(QC_100100_TB)에서 관심 주택을 골라 항목 7개 체크와 메모를 저장. 안전·적합 판정은 하지 않는다. (근거: docs/specs/019-입주전점검-하자기록/spec.md · FR-001)
- FR-002 하자 넣기(QC_100200_TB): 생긴 날, 종류(누수·곰팡이·고장·기타), 메모 500자, 사진 1장(jpg·png·webp, 4MB: Vercel 요청 한도 4.5MB). FR-003 최근 날짜 순, 본인만 볼 수 있는 임시 주소로 사진, 지우면 사진도 지움, 고치기 없음. (근거: docs/specs/019-입주전점검-하자기록/spec.md · FR-002, FR-003)
- 경계: 미래 날짜·목록 밖 종류·빈 메모 거절, 사진 올린 뒤 기록 저장이 실패하면 사진을 지움, 다른 회원의 점검·하자·사진은 읽지도 고치지도 못함(RLS, 저장소 폴더 규칙). (근거: docs/specs/019-입주전점검-하자기록/spec.md · 3-1. 경계·예외)
- 결정(추천안): 새 표 없이 관심 주택 표에 칸 두 개(Q1), 사진 1장(Q2), 관리자는 기록 읽기만·사진은 못 봄(Q3). (근거: docs/specs/019-입주전점검-하자기록/spec.md · 6. 확인 필요 사항)
- QA 실패와 조치: 입력 칸이 여러 칸으로 좁게 갈라짐(사용자 지적) → 한 줄 전체로. (근거: docs/specs/019-입주전점검-하자기록/qa.md · 3. 실패와 조치)
- 하지 않을 것: 원인·책임·안전 판정, 집주인에게 보내기, 하자 예측(PRD 9절), 관심 주택 상세에 같은 탭 따로 두기, 사진 여러 장. (근거: docs/specs/019-입주전점검-하자기록/spec.md · 하지 않을 것)
- 뒤에 더해진 것(2026-11-23, spec 024, 승인 v0.3, qa 완료 C 9/10·H 1/1): 점검 기본 항목이 7개에서 12개가 됐다(배수, 난방·보일러, 전기·콘센트, 방범, 누수 흔적. 누수는 보이는 자국만 기록하고 예측하지 않음). 예전 7개의 체크·메모는 그대로이고 새 5개는 확인 안 함으로 시작한다. (근거: docs/specs/024-점검-내항목-메모/spec.md · FR-007, 머리말) (근거: docs/specs/024-점검-내항목-메모/qa.md · 머리말)
- 같은 spec으로 관심 주택마다 내 항목(집마다 10개, 이름 40자, 이름 고치기·지우기 가능)과 모든 항목의 항목별 메모(200자)를 쓸 수 있다. 집 전체 메모(500자)는 그대로이고, 새 표·칸 없이 move_in_checklist 칸의 모양만 넓힌다. "확인한 항목 N / 전체"는 내 항목까지 센다(가정). (근거: docs/specs/024-점검-내항목-메모/spec.md · FR-001~FR-006, 관련 자료)
- 사람 QA(2026-11-20, 운영 화면·관리자 가상 계정): H-1901 통과(관심 주택 2곳에 다른 체크·메모가 다시 열어도 남음, "(3/7)"처럼 보임. 체크가 "확인함"이라 문제 여부는 메모에만 남고, 두 집을 나란히 보는 화면은 없음). H-1902 통과(샘플 그림으로 저장·사진·지우기, 지운 뒤 저장소 사진 파일도 없어진 것을 대시보드로 확인. 좁은 화면에서 사진 위치가 어색함). (근거: docs/specs/019-입주전점검-하자기록/qa.md · H-1901, H-1902)
- 탭 이름(IA v1.17): QC_100100_TB "입주 전 점검"(셋째 탭), QC_100200_TB "하자·환경 기록"(둘째 탭). 화면에는 보드 표기 "하자/환경 기록"을 쓴다(qa 022 #15). spec 022 v0.5에서 입주 전 점검은 지금 데이터 그대로(항목 추가·항목별 메모는 추후 기능). 이 추후 기능은 spec 024가 만들었다. (근거: docs/specs/024-점검-내항목-메모/spec.md · 머리말 근거 문서) (근거: docs/IA.md · ## IA 표 QC_100100_TB, QC_100200_TB) (근거: docs/specs/022-디자인-전체-수정/qa.md · 4. 실패와 조치 #15) (근거: docs/specs/022-디자인-전체-수정/spec.md · 변경 기록 v0.5)

## 확인 필요
- spec·plan 승인 전. C-1904(실제 저장·사진은 시험 계정 필요)는 부분 통과로 남아 있다. (근거: docs/specs/019-입주전점검-하자기록/spec.md · 머리말) (근거: docs/specs/019-입주전점검-하자기록/qa.md · 머리말)
- spec 019 FR-001은 아직 "항목 7개"로 적혀 있고 spec 024 FR-007이 12개로 늘렸다. spec 024 안에서도 FR-002는 "기본 7개 항목은 지우지 못한다", 제외 범위는 "기본 항목(12개)"라 적는다. 숫자를 맞출지 spec 024 담당에게 확인. (근거: docs/specs/019-입주전점검-하자기록/spec.md · FR-001) (근거: docs/specs/024-점검-내항목-메모/spec.md · FR-002, FR-007, 5. 제외 범위)
- spec 024 qa C 한 건은 관심 주택이 한 곳뿐이라 다른 집을 오가는 확인을 못 해 부분 통과다. (근거: docs/specs/024-점검-내항목-메모/qa.md · 머리말)
