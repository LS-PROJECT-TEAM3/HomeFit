# 화면-메뉴와 화면 목록

> 메뉴 구조, 화면 ID 규칙, 네비게이션, URL 규칙. IA v1.17(2026-11-21)부터 왼쪽 사이드바 대신 위쪽 메뉴다.

## 내용
- 사용자 메뉴(IA v1.19): 위쪽 메뉴 맞춤 공고(공공임대 모집 / 청년 주거지원 정책), 알림(= 위험·기회 알림), 내 일정, 더보기 ▾(집 비교, 집 점검, 에너지 분석, AI 도우미). 홈은 왼쪽 로고로 간다(v1.19). 오른쪽 이름 메뉴에 설정(내 집 / 공고·정책 조건 / 관심 지역 / 알림 설정), 관리자(관리자에게만), 로그아웃. 관리자 메뉴: 회원, 수집 현황, 사건 현황, 흐름 화면, 시뮬레이터, 채점 결과, 위키 챗봇. (근거: docs/IA.md · 머리말 작성일 / 버전, ## 메뉴구조도, ## 확인된 사항 "사용자 메뉴")
- 탭 이름(v1.17, 캔버스 흐름 2): 집 점검은 결로 위험 / 하자·환경 기록 / 입주 전 점검 / 건축물 정보 순서(옛 결로 위험 시뮬레이터 / 입주 전 품질 점검 / 주거환경·하자 기록 / 건축물 기본 정보), 에너지 분석은 전기 / 난방비(옛 예상 에너지 사용량 + 월별 예상 비용을 "전기" 하나로, 냉난방비 시뮬레이션 → 난방비), AI 도우미는 기록 찾기 / 처리 기록 / 공공데이터 출처(메뉴·제목 이름만 "AI 도우미"로, 화면 ID KN_050000_PG는 그대로). 청년 정책은 메뉴에서 빠지고 맞춤 공고 안 탭이 됐다. (근거: docs/IA.md · ## IA 표 QC_100000_PG~QC_100300_TB, EN_110000_PG~EN_110200_TB, KN_050000_PG, PL_090000_PG)
- 이름 바꾸기: 내 정보 → "설정"(이름 메뉴 안), 계정·알림 탭(MY_030400_TB) → "알림 설정"(슬랙 알림·웹 푸시 알림만, 로그아웃은 이름 메뉴로). 위쪽 메뉴 이름만 "알림"(폭 때문), 화면 제목·안내 문장은 "위험·기회 알림". 새 용어 "설정", "더보기", "알림 설정", "웹 푸시 알림"(v1.16). (근거: docs/IA.md · ## IA 표 MY_030000_PG, MY_030400_TB, ## 용어 정의)
- 합친 화면(v1.17): 집 비교 CP_040000_PG가 탭 없는 한 화면이 되어 실질 주거비 비교 CP_040200_PG·추천 결과 CP_040400_TB가 "보류"로 바뀌고 옛 주소는 /compare로 보낸다. 월별 예상 비용 EN_110100_TB도 "보류", 옛 주소는 /energy로. 주소·화면 ID·코드 이름은 그대로 둔다. v1.18: 집 비교는 기본형(띠 없음), 비교 현황(내 집 + 2곳, 항목별 최저값, 네 칸이 다 차야 합계) + 관심 주택 카드 + 등록·고치기 옆 창. (근거: docs/IA.md · 머리말 작성일 / 버전, ## IA 표 CP_040000_PG, CP_040200_PG, CP_040400_TB, EN_110100_TB)
- 화면 ID 앞머리: HM 홈, MB 로그인, IC 위험·기회 알림(사건), MY 내 정보(v1.17부터 화면 이름은 설정), CP 집 비교, KN 기록 찾기(v1.17부터 메뉴 이름은 AI 도우미), SC 내 일정, NT 맞춤 공고, PL 청년 주거지원 정책(v1.5), QC 집 점검·EN 에너지 분석(v1.8), AD 관리자. 끝의 PG는 페이지, TB는 탭, MD는 모달이다. (근거: docs/IA.md · ## IA 표)
- 우선순위 표기: MVP = Must, 2차 = Should, 보류 = Could. (근거: docs/IA.md · 머리말 우선순위)
- 핵심 목표(사건 알림 → 대응안 승인)까지 홈에서 3 Depth 안에 닿는다. (근거: docs/IA.md · 머리말 Depth 한도)
- 네비게이션 모델(v1.17): 주 네비게이션은 위쪽 메뉴줄, 드롭다운은 더보기 하나. 휴대폰은 "메뉴" 버튼을 열면 주 메뉴 5개(더보기는 펼친 4개)와 아래 계정 묶음. 설정·관리자는 왼쪽 세로 탭(휴대폰은 위쪽 가로 줄), 포스터형 화면은 큰 띠 아래 폴더 탭, 맞춤 공고는 화면 안 탭. 새 사건 배지는 "알림" 옆 숫자(색만 쓰지 않음). 드롭다운은 Enter·Space로 열고 Esc로 닫으면 초점이 버튼으로 돌아온다. (근거: docs/IA.md · ## 네비게이션 모델)
- URL: `/섹션/하위/[id]`(Next.js App Router 폴더와 같음), 거르기는 쿼리(`/incidents?type=policy&status=pending`), 관리자는 모두 `/admin` 아래. (근거: docs/IA.md · ## URL 전략)
- 공통 컴포넌트: 사건 카드, 상태 배지(색과 글자 함께), 출처 표시(수집 자료 / 지난 사건 / 위키 쪽), 빈 화면·불러오는 중·조회 실패("데이터 없음"과 "조회 실패"를 다른 문구로). (근거: docs/IA.md · ## 공통 컴포넌트)
- 목록은 기간·종류·상태 거르기와 한 번에 20개 페이지 나누기를 쓴다. (근거: docs/IA.md · ## 콘텐츠 증가 대응)
- 화면 수(v1.17): 56개 = MVP 48, 2차 0, 보류 8(이 중 PL_090200_TB는 삭제인데 엑셀 원본에서는 보류로 센다). 수집 실행 상세(AD_070201_PG)는 따로 주소를 만들지 않고 흐름 화면으로 본다. (근거: docs/IA.md · ## IA 표 아래 문장, AD_070201_PG)
- v1.9~v1.16 바뀐 화면: 내 일정 SC_060000_PG에 계약 만료 알림(v1.9), 비밀번호 재설정 MB_010300_PG MVP와 새 비밀번호 MB_010301_PG(v1.10), 추천 결과 CP_040400_TB MVP(v1.11, v1.17에 보류), 냉난방비 EN_110200_TB MVP(v1.12), 입주 전 점검 QC_100100_TB·하자 기록 QC_100200_TB MVP이고 MY_030202_PG·CP_040301_TB는 보류(v1.13), 홈 바깥 날씨 카드(v1.14), 직장 및 생활권 분석 PL_090200_TB 삭제(v1.15), 계정·알림 탭에 "웹 푸시 알림" 칸(v1.16, PRD v1.20 FR-35). (근거: docs/IA.md · 머리말 작성일 / 버전) (근거: docs/IA.md · ## IA 표)
- 디자인 틀(포스터형·기본형)과 이 메뉴로 바꾼 이유는 [[결정-포스터형과 기본형으로 디자인 바꾸기]], [[기능-022 디자인 전체 수정]]. (근거: docs/specs/022-디자인-전체-수정/spec.md · FR-010, FR-011)

## 충돌
- 건축물 정보 조회의 범위: IA는 `CP_040303_TB` 건축물 정보를 "외부연동, 보류"로 둔다(근거: docs/IA.md · ## IA 표 CP_040303_TB), PRD는 FR-34를 "Should(v1.8, 사용자 결정 2026-11-18)"로 바꾸고 "건축물 정보(FR-34)는 v1.8에서 1차 조회로 옮김"이라 적었다(근거: docs/PRD.md · ## 7. 기능 요구사항 FR-34) (근거: docs/PRD.md · ## 9. 출시 계획). spec 004 FR-008(v0.4)은 PRD 쪽대로 건축물 조회를 만들었다(근거: docs/specs/004-화면-뼈대/spec.md · FR-008). IA v1.8은 집 점검 아래 `QC_100300_TB` 건축물 정보를 MVP로 새로 두었지만 `CP_040303_TB`는 여전히 "보류"이고, PRD FR-34의 화면 ID는 `CP_040303_TB` 그대로다(근거: docs/IA.md · ## IA 표 QC_100300_TB) (근거: docs/PRD.md · ## 7. 기능 요구사항 FR-34). 고르지 않는다. 팀이 IA·PRD 화면 ID를 맞출지 정한다.
- (풀림) IA 안의 메뉴구조도 "(2차)·(보류)" 표시와 IA 표 MVP가 다르던 것은 v1.17에서 메뉴구조도를 위쪽 메뉴 순서로 다시 써서 없어졌다. (근거: docs/IA.md · ## 메뉴구조도)
- 집 비교 위치: IA v1.19는 집 비교를 더보기 안에 두고(근거: docs/IA.md · ## 네비게이션 모델, ## 메뉴구조도), spec 022 v0.8은 위쪽 메뉴 한 칸으로 꺼냈다(근거: docs/specs/022-디자인-전체-수정/spec.md · FR-010, 변경 기록 v0.8). 또 IA 네비게이션 모델은 집 비교를 포스터형 화면에 넣고(근거: docs/IA.md · ## 네비게이션 모델 보조 네비게이션), IA CP_040000_PG v1.18과 spec 022 v0.3은 기본형이다(근거: docs/IA.md · ## IA 표 CP_040000_PG) (근거: docs/specs/022-디자인-전체-수정/spec.md · 변경 기록 v0.3). 고르지 않는다. IA 담당이 정한다.
- 관심 주택 등록·상세 화면: IA 메뉴구조도는 "관심 주택 등록·상세는 따로"이고 CP_040100_PG(/compare/new)·CP_040300_PG(/compare/[id])는 MVP로 남아 있다(근거: docs/IA.md · ## 메뉴구조도, ## IA 표 CP_040100_PG, CP_040300_PG). spec 022 v0.3은 "옛 상세·등록·비용 비교·추천 주소는 /compare로"이고 등록·고치기는 옆 창이다(근거: docs/specs/022-디자인-전체-수정/spec.md · 변경 기록 v0.3). 고르지 않는다.
- 설정 넷째 탭 이름("알림 설정" ↔ "알림(슬랙·웹 푸시)" ↔ "계정·알림")은 [[기능-022 디자인 전체 수정]]의 충돌 절에 있다.

## 확인 필요
- 화면 ID 앞머리 MY는 IA 표 Location이 "설정"으로 바뀌었는데, 앞머리 뜻(내 정보)을 IA가 따로 고쳤는지는 원본에서 찾지 못했다. IA 담당에게 확인. (근거: docs/IA.md · ## IA 표 MY_030000_PG)
