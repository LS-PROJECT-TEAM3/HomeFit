# 기능-011 에너지비 추정과 에너지 분석

> 전기 사용량을 모르는 집의 에너지비를 한국전력 시군구 가구 평균 사용량으로 추정하고, 내 집의 12개월 예상 전기요금을 보이는 에너지 분석 화면.

## 내용
- 상태: spec 초안 v0.2(Q1 결정 반영, "spec 승인 전"), plan 초안 v0.1("승인 전", 사용자 지시 "승인 받지 말고 진행"), qa "완료"(C 5/5, H 1/1). (근거: docs/specs/011-에너지-추정/spec.md · 머리말) (근거: docs/specs/011-에너지-추정/plan.md · 머리말) (근거: docs/specs/011-에너지-추정/qa.md · 머리말)
- 문제: 이사 전 집이나 관심 주택은 전기 사용량을 몰라 에너지비가 "미입력"으로 빠지고 실질 주거비가 실제보다 낮게 보인다. 에너지 분석 화면은 "범위 밖" 문구로 남아 있었다. (근거: docs/specs/011-에너지-추정/spec.md · 1. 해결하려는 문제)
- FR-001 근거 있는 추정: 그 집 시군구의 한국전력 「가구 평균 전력사용량」(주택용, 가구당 월평균 kWh) 최신 달 값을 한 달 사용량으로 쓴다. 면적은 반영하지 않는다고 화면에 적고, 통계 이름·연도·출처 링크를 함께 보인다. 그 시군구 값이 없거나 수집 실패면 추정하지 않는다. (근거: docs/specs/011-에너지-추정/spec.md · FR-001, E2)
- FR-002 에너지비 순서: 직접 입력 > 전기 사용량으로 계산 > 추정 > 미입력. 추정값은 "추정값" 글자와 합계 옆 "추정 포함"으로 구분하고, 요금은 [[기능-009 실질 주거비 비교]]의 한전 요금표 계산을 그대로 쓴다. (근거: docs/specs/011-에너지-추정/spec.md · FR-002, E1, E3)
- FR-003 에너지 분석 화면: 내 집 기준 예상 한 달 사용량(입력 또는 추정)과 12개월 예상 전기요금 표(7·8월은 하계 누진 구간). 냉난방비 탭은 도시가스 요금을 계산하지 않아 "다루지 않음"으로 둔다. (근거: docs/specs/011-에너지-추정/spec.md · FR-003, E4)
- 결정: 근거 통계는 한국전력 시군구별 가구 평균 전력사용량(Q1, 2026-11-18), IA v1.8에 새 메뉴 EN_110000_PG·EN_110100_TB·EN_110200_TB(Q2), 한 번 읽은 값은 하루 기억(Q4), 전력데이터개방포털 키 이름 `KEPCO_API_KEY`(값은 `.env.local`·Vercel에만, Q3). API는 `houseAve.do`에 연도·월·시도·시군구 코드를 넣어 부른다. (근거: docs/specs/011-에너지-추정/spec.md · 6. 확인 필요 사항 결정)
- 하지 않을 것: 도시가스·난방비, 부가세·기금 포함 요금, 확인하지 못한 수치로 추정, 개인 맞춤 추천 점수, 실제 계량기·한전 계정 연동. (근거: docs/specs/011-에너지-추정/spec.md · 하지 않을 것)
- QA 실패와 조치: 데이터 없는 달이 HTTP 404로 와 오류로 끝남 → 404는 "없음"으로 보고 그 전 달을 본다, 0kWh 입력 때 "통계가 없어"로 잘못 안내 → 고침, 404·지역 실패 분기 시험 추가. (근거: docs/specs/011-에너지-추정/qa.md · 3. 실패와 조치)
- 뒤에 바뀐 것(2026-11-19): E2 "추정 근거가 없으면 미입력"은 spec 017 E4로 바뀌어 한전 값이 없으면 가구에너지패널조사 전국 평균 × 주택 종류·면적 비율로 추정한다([[기능-017 주택 종류·면적 에너지 추정]]). 아파트는 spec 018이 먼저 쓴다([[기능-018 아파트 에너지 사용금액]]). 냉난방비 탭은 spec 016으로 계산기가 생겼다([[기능-016 냉난방비 계산]]). (근거: docs/specs/011-에너지-추정/spec.md · E2)
- QA 실패와 조치 4(PR #15 리뷰): 200인데 모양이 다른 응답(키 오류 등)을 "통계 없음"으로 하루 기억함 → 오류로 처리(팀 규칙 "읽기 실패는 오류로"). (근거: docs/specs/011-에너지-추정/qa.md · 3. 실패와 조치)

## 충돌
- 한전 API 주소·칸 확인 여부: spec 6절은 "API 가이드 확인(2026-11-18)"으로 주소·요청 칸·응답 칸을 적었고(근거: docs/specs/011-에너지-추정/spec.md · 6. 확인 필요 사항 결정), plan 1절은 "주소·요청 칸·응답 칸 이름은 로그인 뒤에만 보여 아직 확인하지 못했다"고 적는다(근거: docs/specs/011-에너지-추정/plan.md · 1. 기술과 버전). 고르지 않는다. plan을 고칠지 담당이 정한다.

## 확인 필요
- spec·plan은 "승인 전"인데 qa는 "완료"이고 PR #16으로 main에 합쳐졌다. 승인 상태를 문서에 맞출지 담당(예림)에게 확인. (근거: docs/specs/011-에너지-추정/spec.md · 머리말) (근거: docs/specs/011-에너지-추정/qa.md · 머리말)
- 조사 결과 중 면적당 전력 논문 숫자와 2024년 8월 가구당 363kWh 보도는 원문을 직접 확인하지 못했다(추정에는 쓰지 않음). (근거: docs/specs/011-에너지-추정/spec.md · 조사 결과)
