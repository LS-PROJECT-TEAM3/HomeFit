# 연결 지도

PRD 요구(FR)마다 어느 문서에서 왔고 어디로 이어졌는지 보는 표다(spec 009 FR-006, 평가항목 P3-20).
칸에는 문서 ID를 적고, 이어진 것이 없으면 "없음"이라고 쓴다. "없음"이 많은 줄이 아직 덜 만든 요구다.
PR 칸은 git 기록의 PR 합치기 커밋과 커밋 메시지의 출처 ID로 채운다(spec 009 Q7).

| 요구(PRD) | 화면(IA) | 여정(UJ) | 데이터(ERD) | 규칙(spec) | 조각(plan) | 작업 의도(Intent) | PR | QA |
|---|---|---|---|---|---|---|---|---|
| (넣기 묶음 4에서 채운다) | | | | | | | | |
