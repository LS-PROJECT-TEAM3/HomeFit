# 기능-016 냉난방비 계산

> 에너지 분석의 "냉난방비 시뮬레이션" 탭. 지역과 한 달 도시가스 사용량(MJ)을 넣으면 한국가스공사 소매요금표로 요금을 계산하고, 사용량을 줄였을 때 요금도 보인다.

## 내용
- 상태: spec·plan 초안 v0.1(사용자 지시 2026-11-19, 요금표 내려받기 승인, 승인 전), qa "사람 QA 끝"(C 3/3, H 1/1, 2026-11-20). (근거: docs/specs/016-냉난방비-계산/spec.md · 머리말) (근거: docs/specs/016-냉난방비-계산/qa.md · 머리말)
- FR-001 공급 지역 32곳 중 하나와 사용량(MJ) → 기본요금 + 516MJ까지 취사 단가 + 넘는 만큼 주택난방 단가. 부가세 별도와 10%를 더한 어림 금액을 함께. (근거: docs/specs/016-냉난방비-계산/spec.md · FR-001)
- FR-002 사용량을 10%·20% 줄였을 때 요금 표. FR-003 요금표 이름·기준일(2025-12-01)·출처·단위(원/MJ, 부가세 별도), 기본요금이 여럿인 지역은 개별난방 값, 실제 고지서와 다를 수 있음을 적는다. (근거: docs/specs/016-냉난방비-계산/spec.md · FR-002, FR-003)
- 경계: 사용량은 0~100,000MJ, 0이면 기본요금만, 기본요금을 읽지 못한 지역은 없이 계산하고 알림, 원 단위 반올림, 지역을 안 고르면 계산 안 함. (근거: docs/specs/016-냉난방비-계산/spec.md · 3-1. 경계·예외)
- 결정(추천안): 내 집 시군구로 지역을 자동 선택하지 않음(요금표 지역과 시군구를 잇는 표가 없음, Q1), 요금표는 `watch/gas-tariff.json`(Q2), 516MJ 규칙을 모든 지역에(각주 "지역별로 다소 상이" 표시, Q3). (근거: docs/specs/016-냉난방비-계산/spec.md · 6. 확인 필요 사항)
- 하지 않을 것: 사용량 추정·저장, 지역난방·중앙난방·LPG, ㎥ → MJ 변환, 요금표 정기 수집. spec 009의 "도시가스 계산 안 함"을 이 계산기만큼 바꿨다. (근거: docs/specs/016-냉난방비-계산/spec.md · 하지 않을 것, 머리말)
- 결정 변경(2026-11-23, spec 025): "사용량 추정, 내 집에 가스 사용량 저장" 제외가 spec 025로 범위가 바뀌었다. 내 집에 한 달 사용량(MJ)·고지서 달·도시가스 요금 지역을 저장하고, 가스공사 판매량 비율로 12개월을 어림한다. 이 계산기 자체는 그대로다. (근거: docs/specs/016-냉난방비-계산/spec.md · 하지 않을 것) (근거: docs/specs/025-도시가스-12개월-난방비/spec.md · FR-001, FR-002, FR-006, Q2)
- spec 025의 12개월 막대는 이 계산기와 같은 요금 규칙(기본요금 + 516MJ까지 취사 단가 + 넘는 만큼 난방 단가, 부가세 포함 어림)을 쓴다. 요금 지역은 내 집 시군구로 고르되, 시도에 요금 지역이 하나면 자동, 여러 개인 도는 내 집에서 골라 저장한다. 계산기 쪽 지역 직접 고르기는 바뀌지 않는다. (근거: docs/specs/025-도시가스-12개월-난방비/spec.md · FR-003, FR-005, FR-006)
- 사람 QA H-1601 통과(2026-11-20, 운영 화면·관리자 가상 계정): 샘플 값(서울, 1,500MJ)으로 계산식·고지서와 다른 이유·10%/20% 줄인 표가 보임. 실제 고지서와 비교는 못 함. 서울은 취사·난방 단가가 같아 516MJ 구분이 결과를 바꾸지 않음(요금표가 실제로 그런지는 확인 못 함). 이름은 냉난방비지만 냉방(전기)은 없음. (근거: docs/specs/016-냉난방비-계산/qa.md · H-1601)
- 화면 변경(IA v1.17, spec 022 v0.6): 탭 이름이 "난방비"(EN_110200_TB). 지금 계산기를 보드 모양으로 두고, 난방비 12개월 막대는 추후 기능. (근거: docs/IA.md · ## IA 표 EN_110200_TB) (근거: docs/specs/022-디자인-전체-수정/spec.md · 변경 기록 v0.6) 이 "추후 기능"은 spec 025가 만들었다(승인 v0.2, qa 완료 C 11/11·H 1/1). (근거: docs/specs/025-도시가스-12개월-난방비/spec.md · 머리말) (근거: docs/specs/025-도시가스-12개월-난방비/qa.md · 머리말)

## 확인 필요
- spec·plan 승인 전. 실제 도시가스 고지서와 비교한 기록은 없다. (근거: docs/specs/016-냉난방비-계산/spec.md · 머리말) (근거: docs/specs/016-냉난방비-계산/qa.md · H-1601)
- spec 016 Q1 결정("요금표 지역과 시군구를 잇는 표가 없어 자동 선택하지 않음")은 그대로인데, spec 025 Q1은 시도에 요금 지역이 하나면 자동으로 고른다. 계산기와 12개월 막대가 서로 다르게 지역을 정하는 것이 의도인지, spec 016 Q1에 spec 025를 적을지 담당에게 확인. (근거: docs/specs/016-냉난방비-계산/spec.md · 6. 확인 필요 사항) (근거: docs/specs/025-도시가스-12개월-난방비/spec.md · Q1, FR-006)
