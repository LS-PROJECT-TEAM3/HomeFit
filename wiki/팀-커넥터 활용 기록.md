# 팀-커넥터 활용 기록

> 개발할 때 Claude가 외부 서비스(Supabase·Vercel·GitHub 등)에 연결해 실제로 한 일과, 연결에 실패해 다른 길로 간 일. ERD와 실제 DB 대조 결과도 여기 있다(P3-19, P3-16).

## 내용
- 커넥터는 개발 때 Claude가 외부 서비스에 연결해 일하는 길이다. 설치만 한 것은 세지 않고, 앱이 부르는 API는 [[데이터-데이터 출처와 한도]]에 따로 있다. 토큰·키는 적지 않는다. (근거: docs/connectors.md · 머리말)
- 서로 다른 커넥터 3개의 실제 사용(안내서 기준 2개 이상): A Supabase 커넥터(마이그레이션 적용 `apply_migration`, 확인 질의 `execute_sql`, 가상 계정에 관리자 권한 주는 SQL 한 줄), B Vercel 커넥터(배포 목록·상세, 운영 환경변수 확인), C GitHub 커넥터(PR #8·#11 만들기, PR #5·#7 승인·병합). 셋 다 예림님 PC, 개발 때만 쓰고 앱 실행에는 쓰지 않는다. (근거: docs/connectors.md · 1. 지금까지 확인된 사용)
- 커넥터가 아닌 보조 도구: 명령줄 `gh`(선우·서윤 PC, PR 만들기·리뷰), Claude 앱 내장 브라우저(선우: 개발 서버 화면 17곳 검수·노션 제안서 읽기, 현경: 수업 위키 읽기), Claude in Chrome(선우: Supabase 대시보드 읽기만). 2·3번을 평가에 넣을지는 팀이 정한다. (근거: docs/connectors.md · 1. 지금까지 확인된 사용)
- 실패와 대체: Notion 커넥터 404(페이지 권한 없음) → 내장 브라우저, 현경 PC GitHub 연결 인증 오류, 서윤 PC GitHub MCP 연결 오류 → `gh`, 선우 계정 Supabase 커넥터 "권한 없음"(초대 전 개인 조직에만 허용) → 크롬으로 대시보드 읽기. (근거: docs/connectors.md · 2. 연결을 시도했으나 실패한 것)
- 선우 검수(2026-11-18 오전, 일반 계정): 화면 17곳 열림, 관리자 주소 4곳 막힘, 잘못된 입력은 저장 안 됨, 기록 찾기·챗봇은 출처와 함께 답함. 어색한 점 5개(계약 형태 "모름"인데 만료일 보임, 출처 화면에 온통청년 없음 등). 관리자 화면·알림 거절·슬랙은 확인 못 함. (근거: docs/connectors.md · 3. 선우 검수 시험 (2번 내용))
- ERD와 실제 DB 대조(2026-11-18 오후, 선우, 읽기만): 표 20개·표별 칸 수·RLS 정책 35개가 마이그레이션·ERD와 같음. 칸 이름·자료형·정책 조건식·DB 함수는 확인 못 함. `profiles`·`notification_settings`·`schedule_items`의 "API DISABLED"는 정해진 칸만 고치게 막은 의도한 설정(예림님 확인). (근거: docs/connectors.md · 6. ERD와 실제 DB 대조 결과)
- 대조 뒤 바뀐 것: `audit_logs`는 0019로 생김(PR #11). `chat_logs`는 현경님이 SQL 편집기로 먼저 적용했고 파일 0018은 PR #15로 들어옴(다시 돌려도 멈추지 않음). DB 마이그레이션 기록은 19개(0001~0017, 0019, 0020)로 0018이 없다. 맨 앞 4개는 번호 없는 이름으로 기록됐다. (근거: docs/connectors.md · 6.1 대조한 뒤 바뀐 것)
- 0018 기록 처리: 그대로 둔다(A안, 사용자 결정 2026-11-19). 팀은 `supabase db push`를 쓰지 않고, 쓰기로 하면 그때 기록표 전체를 파일과 맞춘다. (근거: docs/specs/012-위키-챗봇/plan.md · 위험과 대응)

## 충돌
- 0018 마이그레이션 기록을 맞출지: connectors.md 6.1절은 "팀이 정해야 한다(현경님, 미결정)"이고(근거: docs/connectors.md · 6.1 대조한 뒤 바뀐 것), spec 012 plan은 "그대로 둔다(A안, 사용자 결정 2026-11-19)"다(근거: docs/specs/012-위키-챗봇/plan.md · 위험과 대응). 고르지 않는다. connectors.md 담당(선우, 조각 C1)이 반영할지 정한다.

## 확인 필요
